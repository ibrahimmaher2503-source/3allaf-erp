## Consistency Gate

- All 72 source Requirement IDs appear once in this matrix and once as full requirements in `docs/02-prd.md`.
- Every row maps to at least one User Story, User Flow, logical database entity, UI Screen, Development Milestone, Acceptance Criterion, implementation Task, and Security control.
- No row is marked implemented, verified, or complete.
- Quotations are mapped to DM 6.1 as a Proposed scheduling decision because the source Implementation Plan has no quotation DM; owner confirmation is required and the functional requirements remain preserved.
